# Hi, I'm Qianqian Zhou 👋

Ph.D. student in **Petroleum & Geosystems Engineering** at **The University of Texas at Austin**, co-advised by [Prof. Michael J. Pyrcz](https://michaelpyrcz.com/) and [Prof. Maša Prodanović](https://sites.google.com/utexas.edu/masha/home).

I work on **multi-scale subsurface characterization with generative AI and foundation models**. When real data is scarce, I build synthetic data that's representative enough to learn from, then measure exactly how representative it is.

### 🔬 What I'm working on
- **[SynSeis3D](https://github.com/zhouqianqianalana/SynSeis3D)**: an open, geology-aware engine that forward-models 3D seismic volumes with aligned labels for faults, channels, basement, and intervals.
- **Seismic foundation model**: multi-task interpretation learned from synthetic seismic on vision foundation-model encoders (SAM ViT, DINO), with LoRA/adapters and transfer to field surveys.
- **Generative digital rocks**: latent rectified flow (3D VAE + rectified flow) that generates 3D pore structures in about a second, checked with porosity, topology, and uncertainty metrics.
